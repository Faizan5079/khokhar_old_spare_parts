# Khokhar Old Spare Parts website

A responsive static website for Khokhar Old Spare Parts in Jhunjhunu, Rajasthan. It introduces the business, its spare-parts and vehicle-purchase activities, vehicle brands, and direct contact details.

The site includes a sticky responsive navigation, click-to-call and WhatsApp links, a Google Maps link, and English and Hindi descriptions. It does not have ordering, login, payment, enquiry forms, a backend, or a database. The original supplied logo remains in use. Vehicle photos are stored locally in `assets/images/` so the site does not depend on third-party image servers at runtime.

## Run locally

Open `index.html` in a browser, or run a local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.
